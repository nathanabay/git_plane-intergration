## Where the pictures come from

Every image caption starts with its source:

- **Screenshot (test Plane)** and **Screenshot (GitHub)** were captured for the developer handbook from the running test Plane CE v1.4.2 and the public GitHub pages of the test repository (`docs/handbook/HANDBOOK_NOTES.md`).
- **Screenshot (demo instance)** was captured for this manual from the **real git-sync service code and user interface**, run locally:
  - It uses a throwaway in-memory PostgreSQL database (PGlite), seeded with the Acme / Website demo data.
  - Only the two network edges are stand-ins: a small in-memory Plane API and an in-memory GitHub API (`manual/demo/server.ts`).
  - Every page, button, message, audit entry and Development-panel row in these pictures was produced by git-sync's own code from realistic webhook deliveries. The deliveries were signed and sent through the real webhook endpoints, then processed by the real handlers and the ordered outbox.
  - No real Plane, GitHub account or production system was touched.
- **Diagram** and **Illustration** are drawings. An Illustration stands in for a screen that could not be captured.
- **[[SCREENSHOT NEEDED]]** marks a screen that needs a signed-in browser that was not available, such as GitHub's own forms or a Plane work item showing the Development section. Each placeholder names the capture command for later.

All screenshots are redacted before capture: email addresses, IP addresses, tokens, long IDs, the App slug, the Client ID and personal avatars are hidden or replaced. Orange numbered callouts match the numbered steps in the text.

## Rebuilding

From the repository root, on the `docs/user-manual` branch:

```sh
npm ci
npm run manual:all          # seed the demo instance, capture, build and verify
# or step by step:
npm run manual:seed         # start the demo instance with its seed data
npm run manual:capture      # all screenshots; add: -- --only <id>
npm run manual:build        # dist/git-sync-user-manual.pdf, .html and cheat-sheet.pdf
npm run manual:verify       # labels, grammar tables, secrets, links, coverage
```

Playwright, Chromium and markdown-it are installed with `npm i --no-save`, so `package.json` and the lock file do not change. The grammar tables are regenerated by `manual/scripts/grammar-tables.mjs` from the real parsers. `manual/scripts/check-labels.mjs` checks that every bold UI label appears in the source code or in a verified capture.
