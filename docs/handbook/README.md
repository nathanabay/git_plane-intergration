The [Plane + GitHub Developer Handbook](Plane-GitHub-Developer-Handbook.pdf) is an illustrated guide for new developers using Plane Community Edition 1.4.2 and this repository's git-sync integration: sign in, find and plan work, connect a personal GitHub account, understand reference and Smart Commit rules, and follow a task through review and merge. The numbered Markdown files are the chapter sources; image provenance, demo changes and verification limits are recorded in [HANDBOOK_NOTES.md](HANDBOOK_NOTES.md). Build the PDF from the repository root with `node scripts/build-handbook.mjs` after installing its documented local dependencies.
